## 4. Defects and limitations found

| # | Finding | Severity | Action today |
|---|---|---|---|
| S1 | **Module-level receivers are not typed.** A symmetric `Fernet` object created at module level and used there (`f.encrypt`) is reported as a PK_ENCRYPT site at T0. Inside a function the same code is correctly excluded (0 sites; verified). The site always ABSTAINs, so no wrong advice is given, but it adds a false site to the output and CBOM. Same root cause as W5 (method-implied role on unresolved receivers). | Low (safe; precision of the site list) | **Not fixed.** Extending typing to module scope changes evidence for real key usage too. Doing that just before F1 needs care and a regression set. Proposed as an Important task (about 2 h, with tests). |
| S2 | README licence ("none chosen") contradicts pyproject (Apache-2.0); setuptools warns that the TOML-table form is deprecated | Medium (owner decision D5) | Not changed: licence choice is the owner's |
| S3 | My first e2e attempt resolved the `pqscan` entry point before installing it (a script bug, exit 127) | — (audit script) | Fixed in `run_e2e.sh`; re-run clean |
| S4 | Reproducibility verified on Windows 11 only | Low | Linux run optional |
| S5 | The first e2e comparison used a byte compare and reported DIFFERENT for outputs that differ only in CRLF vs LF line endings | — (audit script) | Fixed: `run_e2e.sh` now reports "byte" or "except line endings" identity explicitly |

No defect was found in detection, role inference, the policy engine, hybrid handling, exports or error handling that would justify a scanner code change today.

## 5. Verdict

**Ready to demonstrate, with limitations:**
- installs from the README in a fresh clone;
- passes its tests there;
- scans pyca and PyCryptodome code;
- infers roles and tiers as documented;
- abstains when evidence is missing;
- handles hybrids and broken files safely;
- emits schema-valid, deterministic CBOM and SARIF.

**Limitations:**
- detection and recommendation **accuracy** on real code are unmeasured (no labels);
- module-level typing gap (S1);
- PROTOCOL_CONFIG not detected;
- Windows-only reproducibility evidence;
- licence undecided.
