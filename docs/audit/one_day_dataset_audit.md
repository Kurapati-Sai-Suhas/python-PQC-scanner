## 3. The pyca / PyCryptodome imbalance

- **DV repositories:** pyca 254 imports, PyCryptodome 2 (python-jose 1, authlib 1). 0.8% of DV crypto imports are PyCryptodome.
- **Test repositories:** PyCryptodome 48 of 538 crypto imports (8.9%), in salt and bismuth only. Bismuth was added on 14 Nov specifically to meet the protocol's "two PyCryptodome repositories" requirement.
- **Consequence:** PyCryptodome handling is developed and checked only on synthetic idioms (127 instances) and library-internal demo code (PyCryptodome 4.4.0 self-tests). A PyCryptodome-specific failure would first appear in the sealed test results.
- **Proportionate mitigations within the protocol:**
  - validate the 127 synthetic PyCryptodome instances in loop D2;
  - report PyCryptodome results separately (two repositories → no repository-level inference).
- Adding a DV PyCryptodome repository would change the frozen manifest, so it needs owner approval. fortra/impacket was rejected only on licence metadata.

## 4. Other findings

1. **Test scope dominates the DV candidate frames.** 1,934 of 3,503 candidates (55%) are in test files. The sampler's non-app cap (≤ 1/3 of the counted quota) keeps the primary set at least two-thirds app by design. Non-app results are reported separately.
2. **Stale pilot figure in the adopted protocol.** Protocol Sec. 1 quotes H1a pilot = "51.7% (15/29)". The current pilot data and summary (`docs/pilot/h1_pilot_summary.md`) give **16/30 = 53.3%**. The pilot is circular planning information either way. This is a documentation inconsistency inside a hashed, adopted document; correcting it needs the pre-F1 correction route and owner approval. Not changed.
3. **The baseline manifest still carries the outdated Mehl reason** ("contains results only, no scanner source"). See `research_decisions_and_novelty.md`, D14. Not changed, because the manifest is frozen.

## 5. Limitations that must stay documented

- Real-world accuracy, recall and precision cannot be computed today.
- Synthetic labels are by construction and not human-validated.
- The pilot is circular.
- Inference is limited to the seven fixed test repositories.
- PyCryptodome, DH, DSA, hybrids and protocol configuration are thin or absent.
- There is a single annotator plus an AI-assisted review (no inter-annotator reliability).
