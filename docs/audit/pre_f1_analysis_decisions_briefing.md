**Nothing here is decided.** Each item gives the current text or code, the options, the statistical consequence and a recommendation. Thresholds never change.

**Two kinds of item:**
- **I (interpretation):** settles how an existing hypothesis is computed, where the adopted text leaves a real choice.
- **E (editorial or record):** wording, a record or a hash list.
