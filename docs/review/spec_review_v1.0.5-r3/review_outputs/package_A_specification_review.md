E. Overall assessment (verbatim):
The specification is detailed and mostly internally consistent. The H2 machinery (matching, guard, gate, K_e, bootstrap) matches the production code closely, and the self-attested safeguards are described honestly. The most consequential issues are:
- the calibration acceptance (S16) does not match the plan's own criterion, and F1 depends on that criterion;
- the F-A assumption text printed by the code is outdated;
- H3's comparison with always-recommend is confounded by coverage under the per-site harmful rate;
- H1a's numerator, the κ rule, the H4 quantifier, the H4 synthetic split and several labelling rules (protocol configuration, escaped single-purpose keys, PyCryptodome cipher idioms) are underdefined;
- the paper misstates the amendment history and the confirmatory scope.

All of these can be fixed by small, pre-F1 text or code changes. Internal consistency is not evidence that the hypotheses hold or that the tool is accurate, and nothing here shows the study is validated.
